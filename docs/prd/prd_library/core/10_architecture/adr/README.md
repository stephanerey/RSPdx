# Architecture Decision Records (ADR)

> **PRD Policy:** **LOCKED (template)** — Do **not** edit this file in a project PRD. If you need project-specific changes, **copy** it to a new file and reference it from `PRD.md`.


## Purpose
Store durable architecture decisions in an append-only form.

## Rules
- Copy `ADR-000_template.md` to create a new ADR.
- Use stable IDs: `ADR-###_<short_title>.md`.
- Accepted ADRs SHOULD NOT be rewritten; supersede them with a new ADR.
- Link affected docs, requirements, and features.
