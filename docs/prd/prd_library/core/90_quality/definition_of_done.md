# Definition of Done (DoD)

> **PRD Policy:** **LOCKED (template)** — Do **not** edit this file in a project PRD. If you need project-specific changes, **copy** it to a new file and reference it from `PRD.md`.


## General
- Requirements/spec updated and linked from PR
- Code reviewed
- Verification steps provided

## Feature DoD
- Acceptance criteria met
- Tests added where meaningful
- Logs/errors are handled

## Refactor DoD
- No behavior changes (unless explicitly approved)
- Tests pass
- Docs updated for structural changes
