# Domain Index

## Purpose
Provide the domain-specific entry point when a project cannot be understood correctly from functional and technical documents alone.

## Recommended file set
- `01_DOMAIN_KERNEL.md`
- `02_TRANSVERSE_DOCTRINE.md`
- `modules/*.md`
- `screens/*.md` for critical screens only
- `checklists/domain_review_checklist.md`

## Read order for Codex
1. `PROJECT_RULES` or repository-level `AGENTS.md`
2. `06_domain/01_DOMAIN_KERNEL.md`
3. `06_domain/02_TRANSVERSE_DOCTRINE.md`
4. relevant `modules/*`
5. relevant `screens/*` if any
6. only then start implementation planning
