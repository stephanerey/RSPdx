# 40_active_packs

> **PRD Policy:** **PROJECT (editable)** — This folder is intended to receive only the packs selected for the current project.

## Purpose
This folder stores copies of the specialized packs that were imported from the master library for the current project.

## Rules
- Do not copy unused packs here.
- Record every imported pack in `PACKS_ACTIVE.md`.
- Keep the project truth in the core folders.
- Use the imported pack content as a local guidance layer for the current project.
