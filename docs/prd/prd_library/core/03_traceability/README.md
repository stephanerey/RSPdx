# 03_traceability

> **PRD Policy:** **LOCKED (template)** — Do **not** edit this file in a project PRD. If you need project-specific changes, **copy** it to a new file and reference it from `PRD.md`.


## Purpose
Maintain explicit links between requirements, specs, tasks, and validation.

## What goes here
- The live requirement traceability matrix
- Optional supporting indexes or split matrices for large projects

## Minimal rule
A requirement is not execution-ready until it links to:
- at least one spec or architecture ref
- at least one task
- at least one verification path
