# Import Rules

## Pack import principles
- Import the whole selected pack folder unless there is a good reason not to.
- Keep the original pack folder name.
- Do not rename standard files inside the imported pack.
- Record any local modification after import in `PACKS_ACTIVE.md`.

## Versioning hint
If the library later evolves, compare:
- imported pack version in the project
- current master pack version in the library

Then decide whether the project needs a selective update.
