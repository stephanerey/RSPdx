# Pack Creation Checklist

- [ ] The specialization is recurring across multiple projects.
- [ ] The core template alone does not handle it cleanly.
- [ ] The pack can stay smaller than the full PRD backbone.
- [ ] The pack follows `packs/PACK_STANDARD.md`.
- [ ] The pack clearly lists required impacts on core docs.
- [ ] The pack does not hide critical project truth away from the core.
