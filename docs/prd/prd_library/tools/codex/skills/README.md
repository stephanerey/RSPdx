# Codex Skills

This folder now defines the strategy and templates for Codex skills aligned with the PRD library.

## Read first
- `SKILLS_STRATEGY.md`
- `SKILL_TEMPLATE.md`
- `SKILL_EVAL_CHECKLIST.md`

## Conventions
- one folder per skill
- each skill contains its own `SKILL.md`
- keep one skill = one job
- make the description explicit about when to use it
- do not duplicate the whole PRD inside a skill
- prefer official Codex skill locations (`.agents/skills`, `$HOME/.agents/skills`) when installing skills

## Good candidate skills
- `project-state-summarizer`
- `prd-gap-reviewer`
- `requirements-to-tasks`
- `feature-contract-reviewer`
- `quality-gate-reviewer`
