# Implementation After Domain Review

Use this only after the domain / design understanding step has been validated.

Tasks:
1. implement only the targeted slice
2. preserve the validated invariants
3. keep the implementation close to the existing codebase style
4. list modified files
5. state DB / API / UI impacts explicitly
6. add or update tests when appropriate
7. update the relevant PRD or as-built docs when the implementation changes project truth
