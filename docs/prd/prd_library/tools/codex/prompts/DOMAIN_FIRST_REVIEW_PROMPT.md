# Domain-First Review Prompt

Read first:
- repository `AGENTS.md`
- relevant domain kernel / doctrine docs if they exist
- the relevant module doc
- the relevant critical screen doc if any

Do not code yet.

Tasks:
1. restate the target business / operational flow
2. list the invariants that must remain true
3. list the objects involved and their required relations
4. say what must absolutely appear in the UI or API
5. identify ambiguities, risks, and likely wrong shortcuts
6. propose a short implementation plan in small steps
