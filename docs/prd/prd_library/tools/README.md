# Tools

This folder is reserved for library operations and future automation.

## Subsections
- `project_intake_wizard/` — guided human entry point that generates intake files before PRD completion
- `library_management/` — how to instantiate projects from the master library
- `codex/` — Codex-oriented assets, including templates, prompts, skills strategy, and integration notes
- `governance/` — rules for evolving the library cleanly

## Important principle
Tools support the PRD system; they do not replace the PRD itself.
