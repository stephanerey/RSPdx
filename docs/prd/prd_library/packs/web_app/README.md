# Web App Pack

## Purpose
Add the recurring concerns of browser-based applications: client/server boundaries, authentication, sessions, frontend structure, deployment environments, and operational quality.

## Intended project families
- web applications
- full-stack platforms
- internal dashboards
- portals with browser clients

## Use this pack when
- the user-facing interface runs in a browser
- routing, sessions, auth, or frontend state management matter
- deployment environments and web operations are meaningful concerns

## Do not use this pack when
- the project is only an API service with no browser UI
- the project is only a desktop GUI
