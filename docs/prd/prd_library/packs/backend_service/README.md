# Backend Service Pack

## Purpose
Add the recurring concerns of services, daemons, APIs, workers, and background processes: service boundaries, runtime operations, deployment, observability, configuration, resilience, and interfaces.

## Intended project families
- backend services
- APIs
- workers and daemons
- schedulers and processing services

## Use this pack when
- the main product value is provided by a long-running backend process
- service deployment, monitoring, or interface availability matters
- operational readiness is part of project success

## Do not use this pack when
- the project is only a local CLI tool
- the backend is trivial and fully covered by another main pack
