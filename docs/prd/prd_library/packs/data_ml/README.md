# Data / ML Pack

## Purpose
Add the recurring concerns of data pipelines and machine learning projects: datasets, experiment reproducibility, feature lineage, training/evaluation separation, metrics, and artifact traceability.

## Intended project families
- data processing pipelines
- ML training projects
- evaluation toolchains
- analytics workflows

## Use this pack when
- datasets, derived features, models, or experiments are first-class artifacts
- reproducibility and metric interpretation matter
- training/evaluation workflows are part of delivery

## Do not use this pack when
- the project is only a thin application with trivial analytics
- no reproducible data or model artifact lifecycle exists
