# Python Desktop Pack

## Purpose
Add the recurring concerns of Python desktop applications: local runtime environment, GUI architecture, background work orchestration, packaging, logging, and operator workflows.

## Intended project families
- Python desktop GUI applications
- PyQt / PySide tools
- local operator applications
- instrument control applications

## Use this pack when
- the application runs as a local desktop program
- there is a GUI event loop and user interaction
- background tasks, acquisition loops, or device control threads are relevant

## Do not use this pack when
- the project is only a CLI or backend service
- the project has no persistent GUI runtime
