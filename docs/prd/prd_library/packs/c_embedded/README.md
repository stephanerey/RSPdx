# C Embedded Pack

## Purpose
Add the recurring concerns of firmware and embedded C projects: hardware context, toolchain, real-time behavior, memory constraints, peripherals, bring-up, and board-level validation.

## Intended project families
- MCU firmware
- RTOS-based embedded software
- board support packages
- low-level device control software

## Use this pack when
- the target is a microcontroller, SoC, FPGA softcore, or board-level embedded runtime
- hardware peripherals and timing constraints matter
- flashing, debugging, or bring-up are part of the project lifecycle

## Do not use this pack when
- the project is only a desktop or web application
- hardware is mocked and not an engineering concern of the project
