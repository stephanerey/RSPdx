# Packs

Packs are specialized overlays that extend the generic core PRD.

## What a pack is
A pack is a reusable module focused on one project family or one recurring concern.
A pack does not replace the core PRD.
It adds domain-specific guidance, checklists, and expectations.

## What a pack is not
A pack is not a second PRD backbone.
A pack should not duplicate the whole core structure.
A pack should not become the only place where critical project truth exists.

## Standard references
- `PACK_STANDARD.md` — required format and rules for all packs
- `PACK_SELECTION_GUIDE.md` — how to choose packs for a project
- `_pack_template/` — skeleton to create a new pack
