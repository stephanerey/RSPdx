# CLI / Library Pack

## Purpose
Add the recurring concerns of reusable libraries and command-line tools: API surface stability, UX of commands, packaging, versioning, compatibility, and documentation quality.

## Intended project families
- CLI tools
- reusable libraries
- SDKs
- internal developer tools

## Use this pack when
- the main deliverable is a command-line interface or reusable code package
- public or semi-public API stability matters
- packaging and versioning are part of the product contract

## Do not use this pack when
- the project is dominated by GUI or service operations
- the code is throwaway and no interface contract matters
