# PRD Library

Reusable PRD library for building project documentation from a generic core plus specialized packs.

Choose your language:
- French guide: `README_FR.md`
- English guide: `README_EN.md`

Fast entry points:
- `START_HERE.md`
- `QUICKSTART.md`
- `run_wizard.py`

Internal library contents live under `prd_library/`.

Codex bootstrap templates live under `prd_library/tools/codex/templates/`.
